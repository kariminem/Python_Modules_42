# 42_Python

A comprehensive repository containing all my solutions for the **42 Python** modules, tracking my journey from Module 00 to Module 10.

---

## 📌 About the Project

The 42 Python Piscine/Data Science branch is designed to take students from basic Python syntax to foundational data science concepts. It covers object-oriented programming, data manipulation, visualization, and efficient matrix operations.

> 💡 **Note:** All code adheres to strict 42 styling guidelines and best practices (proper error handling, `flake8` compliance where applicable, and no forbidden libraries).
